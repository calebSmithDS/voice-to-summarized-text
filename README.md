# voice_to_summarized_text

This app can take an mp3 file and, through the OpenAI Whisper API, can transcribe the audio. Then uses OpenAI and a custom prompt to summarize the content into a markdown file. This file is then stored in the specified folder. In this case, my Obsidian notes app transcription folder with the appropriate date as the file name.

# Features 
- Transcribe audio
- Summarize transcription
- Save in markdown in notes app

# Tech Stack
- OpenAI API
- Python 3.10

Notes
This app will be expanded to allow for input through the command line, rather then changing the file
